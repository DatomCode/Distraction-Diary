# Distraction Diary

A VS Code extension that helps you manage context switching by remembering **where you were in your code** when you got distracted — and teleporting you straight back.

## What it does

Distraction Diary watches for two kinds of distractions and quietly records your location (file, line, and column) for each one:

- **Window focus loss** — you switch to another app, a browser tab, or any other window.
- **Idle time** — you stop typing or moving around for a configurable number of minutes (on by default after 3 minutes).

When you come back to VS Code, the extension pops up a welcome-back message with a one-click **"Go to Line N"** action that opens the file you were in and places your cursor exactly where you left off.

Every distraction is also logged in a session diary:

- Open the **Distraction Diary** tree view from the Activity Bar to see a list of recorded distractions with the file, line, and timestamp of each one.
- Click any record — or use the **Distraction Diary: Jump to Recorded Location** command — to teleport back to that spot.

The diary is in-memory for the current session, capped at a configurable number of records (default 200), so it never writes anything to disk and never tracks what you typed.

## Settings

| Setting | Default | Description |
| --- | --- | --- |
| `distractionDiary.idleTimeoutMinutes` | `3` | Minutes of inactivity before an idle distraction is recorded. Set to `0` to disable idle tracking. |
| `distractionDiary.recordFocusLoss` | `true` | Record a distraction every time the VS Code window loses focus. |
| `distractionDiary.maxRecords` | `200` | Maximum number of distraction records to keep in the session diary. |

## How to run it

You need [Node.js](https://nodejs.org/) (v18+) and VS Code 1.85+.

### 1. Install dependencies and compile

```bash
cd extension
npm install
npm run compile     # tsc -p ./ — emits JS into out/
```

For development with live rebuilds:

```bash
npm run watch
```

### 2. Launch the extension in a development host

Open the `extension/` folder in VS Code, then press **F5** (or *Run → Start Debugging*). This starts a second VS Code window ("Extension Development Host") with Distraction Diary installed. To try it:

1. Put your cursor anywhere in a file.
2. Switch to another app, then switch back — you'll get the welcome-back popup with the **Go to Line N** action.
3. Or stay idle for 3 minutes and type something — same popup appears.
4. Click the Distraction Diary icon in the Activity Bar to see the session log and click a record to jump to it.

### 3. Run the smoke test (no VS Code required)

The repo includes a headless smoke test that stubs the `vscode` API and drives the full lifecycle — activation, focus loss, refocus, idle detection, and the jump command — with 28 assertions:

```bash
node .smoke.js
```

It exits `0` and prints `ALL TESTS PASSED (28/28)` when everything works.
